# 六市预报文件名对照

这里的每个文件对应一个**研究单元**，不是六个省。文件名格式为 `<单元编码>_hourly.csv`（未来 168 小时逐小时气象数据）或 `<单元编码>_daily.csv`（按北京时间聚合的每日气象数据）。同一单元的每日体感温度及年龄组健康风险在 [`data/processed/units/`](../../processed/units/) 下，后缀为 `_health_risk.csv`。

`core` 表示列出的几个区合并后的主城区；其余六位数字是数据边界所用的行政区代码。主城区和单区分别计算，不能把各区结果简单相加。六市共 39 个研究单元。
