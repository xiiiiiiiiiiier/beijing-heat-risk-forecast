# 顺义相关正式变量更新

用户追加授权提交、推送，且明确允许同步刷新北京全部研究单元。原因是 `api.py::validate_snapshot` 要求北京各单元使用同一更新批次，不能仅换顺义和urban而让北京其余单元留在旧批次。

基于远程最新提交 `196f7cee31b2a5a787f6f290823120eb8c80b9d7`，源边界和代码与最初核查版本相同。几何修复已提交为 `af1eb59`。

正式IFS输入的更新时间为 **2026-10-14 19:25:57（UTC+8）**，246个唯一格点、168个连续小时，共41,328条格点小时记录。由仓库原 `fetch_city` 获取，使用新静态权重，调用原 `weighted_hourly`、日统计、HI、AT和分级函数重算。

更新40个北京正式CSV文件：12个单元的逐小时和每日天气24文件；11个非urban单元的AT/水汽压/两年龄组风险11文件；urban的逐小时HI及日峰值/分类2文件；北京core旧版接口的小时、日、风险镜像3文件。其他五市结果沿用上述远程基线，未重新获取或改写。

顺义正式变量包含T、RH、风速、日均/最高温、日均湿度/风速、小时数与完整日标志、水汽压、AT、两年龄组风险、来源/模型/更新时间。北京urban正式变量包含上述天气变量及逐小时HI、效应分类、日HI峰值、峰值时刻和分类。顺义HI仍只在科研诊断证据中提供，没有新增顺义正式HI产品，也未给urban新增正式AT产品。

`scripts/audit_beijing_refresh.py`用保存的同一逐格输入独立复算全部40文件，逐列核对数值、时间及分类，全部通过。整个仓库45单元、141文件的API快照校验通过；全套61项测试通过。
